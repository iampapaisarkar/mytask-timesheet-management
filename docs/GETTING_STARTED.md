# Getting started (local development)

This is a short pointer. **Full step-by-step instructions** (backend, web, iOS, Android) live in the root [README.md](../README.md).

Quick commands from repo root:

```bash
npm install --legacy-peer-deps

# backend (separate install)
cd backend && npm install && npm start

# web
npm run web

# mobile
npm run mobile
npm run mobile:ios
npm run mobile:android
```
