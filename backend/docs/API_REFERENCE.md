# Backend API Reference

See repository root [API_ANALYSIS.md](../../API_ANALYSIS.md) for the complete endpoint table.

## Conventions

- Mount: `/api`
- JSON body; multipart where uploads apply
- Success/failure metadata in `info` (injected in `index.js`)
- Auth: `Authorization: Bearer <Firebase ID token>`
- Org: `ms-organisation-id`, `ms-organisation-code`, `ms-organisation-name`
